# Build, buy or skip an AI tool

Use this before adding any new AI tool, subscription or automation.

## Three questions
1. **Which repeated task does it fix, and how often does that task happen?** If you cannot name the task and its frequency, skip it.
2. **What does it cost to run and to maintain, and what happens when it breaks?** Count your time, not just the price.
3. **Is there a smaller version you could try this week?** A prompt, a template or a manual routine often answers the question before any tool does.

## Decide
| If | Then |
|---|---|
| The task is rare or unnamed | Skip |
| A prompt or template solves most of it | Use the prompt; revisit in a month |
| It is repeated weekly, a good product exists and the data can leave your machine | Buy, with a trial first |
| It is repeated, specific to you, and the essential step is simple code | Build, and keep the model out of the critical path |
