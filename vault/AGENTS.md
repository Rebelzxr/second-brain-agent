# AGENTS.md: rules for AI agents working in this vault

This vault is a second brain: notes you collect, and notes your agents distil for you. Agents read it to answer questions and add to it when you ask. These rules keep it trustworthy.

## Where things go

| Folder | What lives there | Who writes |
|---|---|---|
| `0_Inbox/Clippings/` | Web pages saved with Obsidian Web Clipper, pasted articles | You |
| `1_Raw/` | Transcripts, exports, reports, long dumps | You or a collector |
| `2_Wiki/Digests/` | One digest per source: what it says and what it means for you | Agent (`digest` skill) |
| `2_Wiki/Concepts/` | One note per idea, built from several sources | Agent (`compile-wiki` skill) |
| `2_Wiki/Decisions/` | Frameworks for choices you make more than once | You or agent |
| `2_Wiki/Compounds/` | Patterns that showed up in three or more digests | Agent, proposed first |
| `3_Learning/` | Daily learning notes in your own words | You, or agent from what you said |
| `3_Learning/Weekly/` | Weekly reviews | Agent (`weekly-review` skill) |
| `Templates/` | Note templates | You |

`2_Wiki/INDEX.md` is the map. Agents read it first, and update it whenever they add a note.

## Rules

1. **Read before you write.** Search the index and existing notes first. Update a note instead of creating a near-duplicate.
2. **Never delete or rewrite what the owner wrote.** Raw files and learning notes are the record. Add, link and summarise; do not overwrite.
3. **Every claim has a source.** Link the source note or URL. Keep "the source says", "I infer" and "unknown" separate.
4. **Your words, not theirs.** Digests paraphrase. Quote at most a short line, with credit.
5. **Link generously.** Use `[[Note name]]` links so the graph shows how ideas connect.
6. **Private stays private.** Do not copy client details, money figures or personal messages into shared notes. Never send vault content to another tool unless the owner asks.
7. **Answer from the brain first.** When asked a question, search the vault and cite the notes you used. Say plainly when the brain has nothing on it, before looking anywhere else.
8. **Invent nothing.** No made-up statistics, quotes or results. If a number matters, find its source or mark it unknown.

## File names

- Digests: `YYYY-MM-DD - <Source> - <Title>.md`
- Concepts: `<Concept name>.md`, a plain noun phrase
- Learning: `YYYY-MM-DD.md`
- Weekly: `YYYY-Www.md` (for example `2026-W39.md`)
